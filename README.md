# Test01

这是一个简单的 C 语言算法练习项目，包含常见算法示例。

## 目录

- [Algorithm_Gossip.c](Algorithm_Gossip.c)：斐波那契数列示例程序
- [hanoi.c](hanoi.c)：汉诺塔示例程序

## 编译方式

在 Windows 下使用 GCC：

```bash
gcc -std=c11 -Wall -Wextra -pedantic Algorithm_Gossip.c -o Algorithm_Gossip.exe
```

运行：

```bash
Algorithm_Gossip.exe
```

## 说明

该项目适合用于 C 语言入门学习，帮助理解循环、数组和算法实现。
